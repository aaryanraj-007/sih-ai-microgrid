## 📖 Project Overview
Standard programmable logic controllers (PLCs) in isolated polar microgrids (like India's Bharati Station) operate on **reactive** logic—responding to voltage drops only after they happen, heavily relying on polluting diesel generators. 

This solution replaces static PLCs with an **AI-Driven Hierarchical Microgrid**. By utilizing deep learning for weather/load forecasting and edge-deployed Reinforcement Learning for dynamic load balancing, the system shifts energy management from reactive to **predictive**. 

## ⚙️ Inputs and Outputs (How it Works)

### 📥 Inputs (The Data Pipeline)
1. **Historical Telemetry (MongoDB):** The Python backend fetches massive historical weather datasets generated by the AntAWS (Zhongshan) station, located just 3km from Bharati station.
2. **Sub-Zero Physics Engine:** The raw weather data is processed through the Ideal Gas Law (`ρ = P / (R * T)`) to account for highly dense polar air and sub-zero solar temperature coefficients.

### 📤 Outputs (The AI Control Logic)
1. **PyTorch LSTM Forecasts:** The AI outputs highly accurate `T+1` (1-hour forward) predictions of wind and solar yields.
2. **Reinforcement Learning (PPO) Actions:** The AI outputs millisecond commands to local Edge Relays (simulated via MQTT) to either:
   * **Auto-brake turbines** during a Katabatic storm.
   * **Route power** to battery thermal containment.
   * **Shed non-critical loads** (science labs) to prioritize life-support heating.
   * **Pre-ramp diesel** only when absolutely mathematically necessary.

## 🏗️ 11-Pillar Offline-First Edge Architecture
Because polar stations face severe satellite internet disruptions, the system is designed to be **air-gapped and survivable**:

1. **Cloud Data Lake (`fetch_cloud_data.py`)**: MongoDB Atlas ingests AntAWS telemetry for mainland deep learning training.
2. **Physics Engine (`core_simulation.py`)**: Calculates dynamic Air Density.
3. **Battery Intelligence (`bems_logic.py`)**: Algorithmically derates Li-Ion battery capacity (SOC) in freezing temperatures.
4. **AI Forecaster (`ai_forecaster.py`)**: PyTorch LSTM network exports lightweight ONNX models to the Edge.
5. **RL Central Brain (`rl_agent.py`)**: Stable Baselines3 (PPO) reinforcement learning agent executes load shedding.
6. **IoT Telemetry (`telemetry_broker.py`)**: Simulated MQTT sensor network.
7. **State Management (`state_manager.py`)**: Local SQLite database to ensure memory survives offline.
8. **API Gateway (`api_gateway.py`)**: FastAPI server connecting the database to the dashboard.
9. **Data Pipeline (`simulate_dataset.py`)**: Pandas-driven testing loop.
10. **PLC Failsafe (`failsafe_fallback.py`)**: A physical watchdog. If the AI crashes, traditional PLCs bypass the software and hard-start the diesel generator to save lives.
11. **Command Dashboard (`/dashboard`)**: The Next.js Explainable AI (XAI) UI.

## 💻 How to Run Locally

### 1. Run the Next.js Dashboard
```bash
cd dashboard
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the Edge Command Center.

### 2. Run the AI Pipeline (Python)
Ensure you have Python 3.11+ installed.
```bash
pip install -r requirements.txt # Make sure torch, stable-baselines3, pymongo are installed
python ai_forecaster.py
```
